### Carl

Carl is a free and open-source operating system built with the goal of providing a modern alternative for personal computers and servers.

> **Status:** 🚧 Experimental (0.1)

## Goals

- Free and open-source operating system.
- Clean and maintainable code.
- Modular architecture.
- Open documentation.
- Community-driven development.
- Modern hardware support.

## Philosophy

Carl is designed to be a project where anyone can learn, contribute, and improve the system.

Carl does **not** copy proprietary source code.

Whenever compatibility with existing technologies is needed, the project may rely on:

- Public documentation
- Official documentation (when available)
- Community documentation

All implementations are written independently.

## Planned Features

- Custom kernel
- Open-source drivers
- Server support
- Compatibility layers for applications
- Modular system design
- Developer-friendly tools

## Current State

Carl is currently in a very early stage of development.

Many features are not implemented yet.

The primary goal is to build a solid foundation before adding advanced functionality.

## Contributing

Carl is independent and welcomes contributions for individuals, communities, organizations, and companies.

Contributions are reviewed before being integrated into the project.

You can contribute by:

- Writing code
- Improving documentation
- Translating documentation
- Testing
- Reporting bugs
- Sharing ideas

Before submitting a Pull Request:

- Read the documentation.
- Follow the coding style.
- Keep changes focused and easy to review.
